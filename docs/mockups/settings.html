Priority

Who goes first when the GPU is busy. The top line wins; drag a line to move it. Anything not listed waits in turn at the bottom.

  1. SillyTavern 192.168.1.12 · node-fetch
  2. Roleplay door port 11435
  3. General text door port 11434
  4. ComfyUI door port 8188
  5. Everything else waits in turn, first come first served

    "Drop everything" cancels whatever is running the moment that line's request arrives. The cancelled request gets an error. Use it sparingly.
